# Index-Physics
Index-Physics is a minimalist 2D physics module for C++ with a clear separation between `Body`, colliders, and a registration-based `PhysicsWorld`.

## Building
Project files are generated by [Premake5](https://premake.github.io/). The bundled Windows binary lives at `vendor/bin/premake5.exe` so no extra installation is required on Windows.

### Windows (Visual Studio 2022)
```
Setup.bat
```
This invokes Premake to produce `Index-Physics.sln`, the static-library project, and the `Tests` console project. 
Open the solution and build, or invoke MSBuild directly.

### Linux/macOS
```
bash Setup.sh
```
`Setup.sh` uses a vendored executable `vendor/bin/premake5` when present, otherwise it falls back to `premake5` on PATH. By default it generates `gmake2` files on Linux and `xcode4` files on macOS.

### Other Premake actions
`Setup.bat` and `Setup.sh` forward their first argument to Premake, so any supported action works:
```
Setup.bat vs2022
Setup.bat gmake2
Setup.bat xcode4
bash Setup.sh gmake2
bash Setup.sh xcode4
```

The generated solution, project files, and `bin/` / `bin-int/` output directories are gitignored - they are pure build artifacts.

### Running tests
The default startup project is `Tests`. After a build, run:
```
bin\Debug-windows-x86_64\Tests\Tests.exe
```
The runner executes every registered case and reports a summary; exit code is non-zero on any failure.

## Build target
Index-Physics is configured as a **static library** in all configurations (`Debug`, `Release`, `Dist`) on the `x64` platform.

- Project output type: `StaticLib`
- API macro: `INDEX_PHYS_API` is empty for static builds. Define `INDEX_PHYS_BUILD_DLL` (when building) or `INDEX_PHYS_IMPORT_DLL` (when consuming) to switch to a DLL build.
- Per-config defines: `INDEX_PHYS_DEBUG`, `INDEX_PHYS_RELEASE`, `INDEX_PHYS_DIST`.
- Warnings: `Extra` (W4 on MSVC, `-Wall -Wextra` elsewhere).

## Architecture
- **Body**: A single `Body` class with `BodyType` (`Static`, `Dynamic`, `Kinematic`). Carries position, velocity, mass, restitution, and friction.
- **Colliders**: `BoxCollider`, `CircleCollider`, and `PolygonCollider` derive from `Collider`. `PolygonCollider` is treated as a convex local-space polygon for collision queries. A body owns at most one collider; the bidirectional pairing is established by `PhysicsWorld::AttachCollider`.
- **World**: `PhysicsWorld` stores global settings, registration logic, integration, broadphase (uniform spatial hash), narrowphase, and iterative resolution.
- **Queries**: `Physics2D` provides overlap and point queries with and without an active world context. All queries return values (`std::optional<Contact>`), never references to internal storage.

## Behavior
- Only bodies and colliders registered in `PhysicsWorld` are simulated.
- Gravity affects only bodies of type `BodyType::Dynamic` (when gravity is enabled for that body).
- World bounds can be enabled globally; per-body boundary checks can be toggled.
- Collision normal points from `bodyA` toward `bodyB`; resolution moves A by `-normal * penetration` and applies velocity impulses using `min(restitutionA, restitutionB)` and Coulomb friction. Contact friction is the geometric mean of the two bodies' friction coefficients.
- The velocity solver runs `WorldSettings::solverIterations` passes per step (clamped to at least 1), improving stacked-body stability.
- Narrowphase: precise circle-vs-circle (distance test), circle-vs-box (closest-point test), box-vs-box (AABB), and convex polygon SAT for polygon/polygon, polygon/box, and polygon/circle pairs.
- `SetBodyType` applies sensible defaults:
  - `Static`: gravity off, boundary checks off, velocity reset to zero
  - `Kinematic`: gravity off, boundary checks on
  - `Dynamic`: gravity on, boundary checks on

## Example
```cpp
#include "PhysicsWorld.hpp"
#include "Body.hpp"
#include "BoxCollider.hpp"

int main()
{
    IndexPhys::PhysicsWorld world;

    IndexPhys::Body player(IndexPhys::BodyType::Dynamic);
    player.SetPosition({ 0.0f, 2.0f });

    IndexPhys::BoxCollider playerCollider({ 0.5f, 1.0f });

    world.RegisterBody(player);
    world.RegisterCollider(playerCollider);
    world.AttachCollider(player, playerCollider);

    world.Step(1.0f / 60.0f);
    return 0;
}
```
